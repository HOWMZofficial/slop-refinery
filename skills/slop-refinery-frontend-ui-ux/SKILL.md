UNDER_REVIEW is the implementation.

Report findings and suggested fixes only. Do not apply fixes, edit repository files, change Git state, or update the PR.

Runtime testing may change disposable test data in a local or preview environment.

The standard is a UI that is beautiful, polished, and clean, and a UX in which every visible component and interaction makes sense, at any screen size, with touch as well as a pointer. If UNDER_REVIEW changes nothing users see, report that this review does not apply.

Report what you inspected and every defect: anything unpolished, confusing, broken, or out of keeping with the product's design language, and anything that feels like desktop UI squeezed onto a phone or tablet.
